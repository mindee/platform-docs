title: token-cost-chained-extraction-model
---

The initial model (Split, Crop, Classification) is provided at no additional cost to you if it triggers additional processing using at least one Extraction model.

The possible credit consumption scenarios are as follows:

* extraction model not chained ⇒ token usage of initial model
* extraction models chained ⇒ token usage of each triggered extraction model, including any activated [optional features](../../extraction-models/optional-features/).

For all models, token consumption is calculated per page processed as is standard.
